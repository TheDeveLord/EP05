# 2D Платформер
Простая 2D платформенная игра с элементами коллекционирования, разработанная на Python с использованием библиотеки Tkinter.

🎮 Описание
Управляйте синим квадратом, собирайте золотые монеты, избегая столкновения с красными врагами. Игра предлагает три уровня сложности, каждый из которых меняет параметры геймплея и количество собираемых предметов.

🎯 Цель игры
Соберите все золотые монеты на уровне, избегая врагов и не падая вниз. При падении или столкновении с врагом теряется жизнь. После потери всех жизней игра заканчивается.

✨ Особенности
+ Три уровня сложности: Легкая, Нормальная, Сложная
+ Механика прыжков и гравитации
+ Система жизней - при столкновении с врагом теряется жизнь
+ Сбор монет - основная цель для победы
+ Враги с патрулированием
+ Адаптивное поведение врагов - на высокой сложности они быстрее
+ Меню выбора сложности
+ Экран победы и поражения

⚙️ Управление
- Стрелочки вверх и вниз для управления в меню
- Enter для выбора в меню
- В игре передвижение осуществляется стрелочками, а также пробелом
- Esc для выхода в меню

🔑 Запуск
Откройте CMD, с помощью команды "cd" перейдите в папку с файлом, а после "python Main.py"
